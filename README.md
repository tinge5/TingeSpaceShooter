# Tinge Block Shooter

Tinge Block Shooter is a fast-paced arcade-style game built to feel responsive, readable, and fun in a browser environment. The goal was to create a polished action experience that feels competitive without requiring a large or overly complicated game system.

## What the app is

This project is a Block shooter focused on:

- quick reaction gameplay
- score-based progression
- clean arcade feedback and controls
- a lightweight, playable experience that can be shared easily

The concept is intentionally simple: give the player a clear objective, smooth controls, and strong momentum so the game feels engaging immediately.

## How it was built

The game was built using modern web-friendly tooling and a lightweight game architecture so it could stay fast and accessible. I used a structured approach to keep the project maintainable while still focusing on gameplay feel.

I also used GitHub Copilot as a coding partner during development to speed up iteration, help with implementation details, and refine the project workflow. That helped me move faster on gameplay systems, UI logic, and debugging without losing focus on the product goals.

## Why I built it this way

The design decisions were driven by a few key principles:

- prioritize gameplay clarity over unnecessary complexity
- keep controls intuitive and accessible
- create a strong arcade feel with fast feedback
- build something that can be shared and demonstrated easily

This approach keeps the project practical: it feels like a complete game experience, but still remains focused enough to be a strong portfolio piece.

## Tech stack

- React Native + Expo
- TypeScript
- Firebase for app data and backend integration
- React Navigation for screen flow
- Expo Router for app structure

## Project goals

The purpose of this project was not just to build a game, but to demonstrate that I can take an idea from concept to a playable product. It reflects a balance of software engineering, product thinking, and creative execution.

## Summary

Tinge Block Shooter is a compact, polished arcade project designed to show both technical skill and product judgment. It combines fast gameplay, clean architecture, and a thoughtful build process into a project that is easy to understand, easy to play, and strong for employer review.
